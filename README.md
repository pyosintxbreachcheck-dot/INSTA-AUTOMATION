# Instagram Auto Poster

Created By: Shaurya

## Features

- Auto Upload Instagram Reels
- Google Drive Integration
- Modern Dark UI
- Auto Scheduler (24 Hours)
- Logs & Monitoring
- Creator Dashboard

## Setup

1. Enable Google Drive API.
2. Add service-account.json.
3. Configure config.py.
4. Connect Instagram Business Account.
5. Run:

```bash
python main.py
```

## Folder Workflow

Upload videos to your Google Drive folder.

The bot will:

1. Fetch next reel
2. Upload to Instagram
3. Mark as posted
4. Wait 24 hours
5. Repeat
